# blog-posts

Markdown files here publish automatically to `/blog` when pushed to `main`.

See [BLOG_POSTING.md](../BLOG_POSTING.md) for the frontmatter format and setup.

Only `*.md` files trigger the workflow, and this README is ignored by it —
it has no frontmatter, so it would fail validation if it were ever picked up.
Keep it as the only non-post file in this folder.
